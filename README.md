# Memory Card Game

An interactive browser-based memory card matching game developed using HTML, CSS, and JavaScript.

## Features
- Flip card animations
- Card matching logic
- Score tracking
- Responsive design
- Simple and clean UI

## Technologies Used
- HTML5
- CSS3
- JavaScript
